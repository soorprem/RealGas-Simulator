# Changelog

## 2026-11-08

### Scientific application

- Pure-component Peng–Robinson PVT, enthalpy, entropy and fugacity calculations.
- Five component presets, custom input data and explicit reference states.
- Ideal-gas comparison and two-state property changes.
- Ten interactive plots and calculation details with intermediate values.
- Four-page report, flowchart, screenshots and sample outputs.
- Recorded verification: 41 tests, 80 independent scalar PR comparisons and a 350-state reconstruction grid.

### Repository

- Published the complete project under `soorprem/RealGas-Simulator`.
- Added a screenshot-led project page, citation metadata and contribution instructions.
- Added bug-report and feature-request forms, a pull-request template and editor settings.
- Added a GitHub Actions workflow for Python 3.11 and 3.12, independent validation and the four-page report check. The Actions page reports the actual run status.
