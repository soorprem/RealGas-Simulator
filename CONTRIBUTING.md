# Contributing

RealGas Simulator is an undergraduate chemical engineering project for pure-component Peng–Robinson calculations. Contributions should preserve its equations, reference conventions and explainable numerical results.

## Set up

Use Python 3.11 or 3.12 in a virtual environment, then run:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q tests
python validate.py
```

Run the interface with `streamlit run app.py`. See [README.md](README.md) for activation instructions and [THEORY.md](THEORY.md) for the model derivation.

## Make a change

1. Open an issue for a substantial change, describing the physical problem and intended behaviour.
2. Create a branch and keep each change focused.
3. Add a meaningful regression test for a calculation defect or new numerical feature.
4. Run the scientific and interface tests. Compare changed calculations with independent values using identical component constants and reference conventions.
5. Update equations, sample outputs and documentation when behaviour changes.
6. Submit a pull request describing the problem, resulting behaviour and checks actually run.

For changes to the Python UI or calculation modules, regenerate the browser bundle with `python build_browser.py`. If the report content changes, regenerate it with `python build_report.py` and inspect all four pages.

## Scientific review

State temperature, pressure, units, component constants, Cp correlation, root rule and reference state. Distinguish implementation agreement from model accuracy. Do not compare residual entropies defined at different reference conditions without conversion. Do not replace an independently calculated reference with a value generated by the same function under test.

## Style

Use descriptive function names, SI units internally, explicit conversions at interfaces and comments explaining scientific choices. Avoid unrelated formatting changes and new dependencies unless they solve a concrete problem.
